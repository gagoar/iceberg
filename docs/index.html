Below the waterline: what iceberg checks

14 rules. Each one is checkable.

Every violation is quoted in the report. Code blocks, inline code, URLs, and proper nouns are never touched.

    Three more rules sit outside the core 14 and stay off until you pass their flag: --no-em-dash, --no-weakeners and --strip-ai-commentary. Add a jargon list and iceberg flags those words too. The guide and README cover both.

    See it work

    One sentence in. Three sentences out.

    Toggle the same paragraph before and after /iceberg:edit. Each underline is a rule violation. The After text is the tip: what you ship.

    F
    Grade F · 46 words, 1 sentence

    Passive voice, filler adverbs, hedges, and abstract nouns. Eleven flags in one sentence.

    Automatic

    Runs on every plan.

    After install, every plan Claude generates is scored before it reaches you. The report sits at the top of the response. If you want the rewrite, run /iceberg:edit.

    A Stop hook shows the last score as a status message. It reads one local file and makes no network calls.

    ICEBERG SCORE deployment-guide.md

    Evidence

    Tested before it ships.

    3 of 3

    Eval documents where Haiku and Sonnet gave the same grade. No high-severity rule was missed.

    3 skills

    /iceberg:score reads and grades. /iceberg:edit rewrites. /iceberg:jargon builds your jargon list. Documents over 500 words run in a subagent.
