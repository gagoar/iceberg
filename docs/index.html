Automatic

After install, every plan Claude generates is scored before it reaches you. The report sits at the top of the response. If you want the rewrite, run /iceberg:edit.

The rules

14 rules. Each one is checkable.

Every violation is quoted in the report. Code blocks, inline code, URLs, and proper nouns are never touched.

Evidence

Tested before it ships.

3 of 3

Eval documents where Haiku and Sonnet gave the same grade. No high-severity rule was missed.

2 skills

/iceberg:score reads and grades. /iceberg:edit rewrites. Documents over 500 words run in a subagent.
